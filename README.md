# Amazon SDE Intern Prep Hub

A zero-dependency, single-file web application to organize, track, and conquer the Amazon SDE intern interview loop in 14 days.

## The Problem
Interview prep is usually scattered. Candidates juggle endless LeetCode tabs, massive spreadsheets, randomly saved behavioral stories, and PDF study guides. 

## The Solution
I built this tool to centralize everything needed for the Amazon virtual onsite into one offline-first dashboard. It removes the friction of deciding what to study and forces focus on the highest-leverage material.

## Features
* **14-Day Schedule:** A focused, daily battle plan splitting time between technical and behavioral prep.
* **Curated LeetCode Tracker:** 90 high-frequency patterns and Amazon staples, filterable by difficulty.
* **STAR Story Builder:** A framework to draft, tag, and save behavioral stories directly to your browser.
* **LP Drill Mode:** A built-in timer and randomizer for practicing Leadership Principles out loud under pressure.
* **Local Privacy:** Zero database required. All progress saves automatically to your local browser storage.

## How to Run
1. Clone or download this repository.
2. Double-click `amazon-prep-hub.html` to open it in any modern web browser.
3. Start prepping.

## Tech Stack
* HTML5
* Vanilla CSS
* Vanilla JavaScript
